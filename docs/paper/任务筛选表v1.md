# Appendix V2: V1 Benchmark Task Screening Table

## 说明

本表用于整理第一版（v1）Paper-to-Benchmark 任务池。  
评分采用 16 分制，对应以下维度：

1. 任务目标明确性  
2. 实体/工具可枚举性  
3. 关键步骤可拆解性  
4. 前置条件/顺序约束清晰度  
5. 终止条件可自动判定性  
6. failure mode 可标注性  
7. MuJoCo 可复现性  
8. 资产可获得性  

推荐阈值：

- **13–16**：优先纳入 v1
- **9–12**：可纳入候选池，需人工补标或资产替代
- **0–8**：不建议纳入 v1

## 附：v1 开发建议

如果只选两个任务先打通 compiler + evaluator 流水线，建议从：

- **Vial Capping**
- **Rack Insertion**

开始。  
这两个任务的共同优点是：

- 目标状态明确  
- 关键事件序列短而清楚  
- 硬约束好写  
- MuJoCo 近似成本低  
- 资产可快速准备  
- failure mode 易于解释和可视化
